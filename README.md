# 🛒 Product Recommendation System (Python + Streamlit)

A simple yet powerful **Product Recommendation System** built using **Python, Pandas, scikit-learn and Streamlit**.  
It recommends the **top items to users** based on their past interactions using **Collaborative Filtering**.

---

## 🚀 Features

✔ Recommends items based on user interactions  
✔ Uses **Cosine Similarity** to calculate user patterns  
✔ Fully interactive UI using **Streamlit**  
✔ Real-time recommendation results  
✔ Beginner-friendly project but industry-relevant

---

## 🧠 How It Works

1. Each user has rating data for different items  
2. Ratings are stored in a **user-item matrix**  
3. **Cosine similarity** identifies users with similar preferences  
4. Items liked by similar users are recommended
